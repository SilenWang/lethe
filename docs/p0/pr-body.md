## P0 — preparation and contract gates (VYB-2674)

Base: `next/rewrite` (cut from `dev@64b1953`). **Do not merge into `main`.**

This PR adds foundations only; it does not write detection, write-back or UI
business logic. The five CI jobs are the acceptance gate for this branch.

### What is in it

- **Branches/CI:** `.github/workflows/ci.yml` with five jobs on `main`, `dev`
  and `next/rewrite`; every command runs through `pixi` (`pixi.toml` +
  `pixi.lock` committed).
- **Guard:** `tools/guard_no_bare_save.py` + tests + two deliberate violation
  fixtures. Product code may only leave through `postprocess()`.
- **Gates:** `lethe/gates.py` (35/50MB, 40MB part, 150MB XML, 500MB/10k/100:1
  zip-bomb) + `tests/test_gates.py` + en/zh copy with three fallbacks.
- **Corpus:** 90 files (30 docx / 30 xlsx / 30 pptx) with
  `corpus/manifest.csv` (sha256, part count, element checklist, generator
  version) and `corpus/COVERAGE.md`.
- **Assets:** Pyodide 0.29.5 + BetterOffice 0.5.1 vendored under
  `web/assets/vendor` with a 201-file sha256 manifest; no CDN, no micropip.
- **Contract skeleton:** `tools/postprocess_contract.py` + tests for source
  priority, per-part sha256 and compressed-stream identity (implementation in
  P1).

### Review notes / known trade-offs

- `lethe/docio.py` is the frozen v1 exemption (5 call sites). The guard fails
  if that count grows or if the file is deleted but the exemption remains; it
  disappears at the P3 cutover.
- `lint/typecheck` scope is the P0 files: v1 already carries ruff/mypy debt and
  is removed at P3. The scope is explicit in `pixi.toml`.
- The vendored assets add 65.2MB to the repo because P0 requires same-origin
  hosting plus an in-repo sha256 manifest. If repo size becomes a problem, P1
  can move the blobs to a release artifact and keep the same manifest.
- `dev` is frozen at `64b1953`; the v1 baseline bookmark is `cf93bd2`. No
  `v1.3.2` tag is created and `main` is untouched.
