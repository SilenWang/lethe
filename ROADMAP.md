# Lethe — Roadmap

## Current

Lethe is a browser-only, installable PWA:

- `.docx`, `.xlsx` and `.pptx` redaction and restoration;
- deterministic preset/user dictionary matching and pattern rules;
- signed preset dictionary distribution with offline activation and rollback;
- encrypted browser-local mappings and backup import/export;
- strict OOXML fidelity, leak and memory gates;
- static same-origin deployment with offline acceptance.

## Follow-up candidates

- Additional curated preset dictionaries and incremental content releases.
- More language-specific deterministic rules.
- Further reductions in large-file peak memory.
- Release automation for signed dictionary publication.
